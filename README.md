## 📖 Sobre

Repositório com os códigos da disciplina de **Fundamentos de Algoritmos**, desenvolvidos em **Python**.
Reúne exercícios e práticas para treinar lógica de programação e a resolução de problemas passo a passo.

## 🎯 Assuntos praticados

- Variáveis, tipos de dados e operadores
- Entrada e saída de dados
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Listas, strings e dicionários
- Funções e modularização

> ✏️ **Ajuste esta lista** para refletir os assuntos que realmente estão nos seus códigos.

| Tecnologia | Uso |

## ▶️ Como executar

1. Instale o **Python 3.8+** em https://www.python.org/downloads
2. Clone o repositório e entre na pasta:

```bash
git clone https://github.com/gui69961/fundamentos-2025.git
cd fundamentos-2025
```

3. Execute um dos arquivos:

```bash
python nome_do_arquivo.py
```

> No Linux e no macOS, use `python3` no lugar de `python`.
